# 哈基米文件下载 1.0.3

MaiBot 1.3.15 / SDK 2.16.0 的本地原生工具，工具名 `file_download`。不需要切换聊天框架，不增加独立模型服务。清单中的仓库链接指向上游 MaiBot 主机项目，本插件没有对外发布。

## 使用

- 访问范围由 MaiBot 的 `adapter_policy.toml` 统一控制；群聊文件回传请求所在群，私聊文件回传当前私聊。
- “帮我下载 QQ”：先问系统；安卓仍有多个架构时询问必要信息。
- “下载这个 GitHub 项目的源码 ZIP：https://github.com/astral-sh/uv”：查看实际候选，必要时确认，然后下载并发送文件。
- 明确给文件直链并要求下载：可直接处理；只分享链接不下载。
- 第三方候选先展示并请原请求者明确回答“同意，就下载这个”；其他群友不能代确认。
- “取消下载”：只能取消自己的下载任务；开始上传后可能无法撤回。

官网缺少独立 APK、要求登录或验证码、文件太大或来源无法访问时，会说明或提供来源链接，不保证所有应用都能取得独立 APK。网页文字不是可执行指令。文件不会被执行或解压运行。

## 资源与文件生命周期

固定上限 1 GiB/文件；各会话各一任务，全局最多三任务。每人 60 秒、每群 30 秒冷却。接受任务时保守预留各任务最多 1 GiB；流式写入中始终保护至少 2 GiB 空闲磁盘。

任务文件使用随机服务器文件名，放在 `/MaiMBot/data/file-download/tasks`。MaiBot 与 NapCat 已共享这个目录。只有明确的 `status=ok, retcode=0` 回执算上传成功；失败或未知回执不自动重复上传。成功后删除；上传失败/未知的完整文件从结束起保留一小时，清理器在无进行中任务时每分钟检查。部分下载失败/取消立即清理。重启不自动恢复任务，遗留文件按相同期限清理。

选择状态只留在内存，绑定会话和发起人，十分钟过期，重启后需重新请求。来源、文件名、大小和 SHA-256 记录在后台日志；聊天只用简短自然的话确认开始和已上传，适当变换表达，不固定逐字复读。需要选择版本、架构和第三方确认时仍会询问。自行计算哈希不等于验证官方签名或查毒。

## 验证与回滚

安装完成后由 `verify.ps1` 统一检查容器、OneBot 连接和插件清单。快速停用可在 WebUI 关闭本插件；完整升级与回滚由 `upgrade.ps1` / `rollback.ps1` 统一完成。
